# 🔑 Configurable Password Generator

Консольное приложение на Python для генерации надежных, криптографически стойких случайных паролей по заданным критериям. Утилита позволяет пользователю гибко настраивать длину, количество паролей, выбирать типы символов, а также автоматически выгружать результат в файл.

Проект демонстрирует навыки написания безопасного кода, работы со стандартными библиотеками Python, валидации пользовательского ввода и работы с файловой системой.

---

## ✨ Основной функционал / Features

* **🎛️ Гибкая настройка пула символов:** Пользователь сам решает, из чего будет состоять пароль (цифры, строчные буквы, заглавные буквы, знаки пунктуации).
* **🔢 Массовая генерация:** Возможность создать как один, так и целую пачку уникальных паролей за один запуск.
* **📏 Кастомизация длины:** Полный контроль над количеством символов в генерируемых комбинациях.
* **🛡️ Повышенная безопасность:** Использование криптографического модуля `secrets` вместо стандартного `random` гарантирует защиту от предсказания паролей.
* **🛡️ Валидация ввода (Защита от сбоев):** Программа корректно обрабатывает неверный ввод (буквы вместо чисел) и не позволяет создать пустой пул символов.
* **💾 Выгрузка в файл:** Опциональное сохранение сгенерированных паролей в текстовый файл с уникальной временной меткой (таймстемпом) в названии для предотвращения перезаписи.

---

## 🛠️ Стек технологий / Tech Stack

* **Язык:** Python 3.x
* **Использованные модули (Стандартная библиотека):**
  * `secrets.choice` — для криптографически стойкого случайного выбора символов (рекомендовано для паролей и токенов).
  * `string` (`digits`, `ascii_lowercase`, `ascii_uppercase`, `punctuation`) — для быстрого доступа к готовым наборам безопасных символов.
  * `datetime` — для генерации уникальных имен файлов при экспорте.
* **Концепции:** Объединение связанных данных в структуры (кортежи), оптимизированная сборка строк через `"".join()`, обработка исключений (`try-except`), работа с контекстными менеджерами файлов (`with open`).
* **Сборка:** Исполняемый бинарный файл (.exe) для операционной системы Windows.

## 🚀 Как запустить / How to Run

Вы можете использовать программу как готовое приложение или запустить её через исходный код Python.

### Вариант 1: Запуск готового `.exe` (Рекомендуется для пользователей)
Вам **не нужно** устанавливать Python.
1. Перейдите в раздел **[Releases](https://github.com/Mr-Sharkness/Password-Generator/releases)** справа.
2. Скачайте файл `Password-Generator.exe`.
3. Запустите его двойным кликом.

*Примечание: При первом запуске Windows Defender может выдать предупреждение SmartScreen. Нажмите "Подробнее" -> "Выполнить в любом случае".*

### Вариант 2: Запуск из исходного кода (Для разработчиков)
Для запуска и модификации кода вам понадобится **Python 3.x**:

```bash
# Клонировать репозиторий
git clone https://github.com/Mr-Sharkness/Password-Generator.git

# Перейти в папку проекта
cd Password-Generator

# Запустить приложение
python "Password Generator.py"
