# 🔑 Configurable Password Generator

Консольное приложение на Python для генерации надежных, случайных паролей по заданным критериям. Утилита позволяет пользователю гибко настраивать длину, количество паролей, а также выбирать типы символов, которые будут использоваться при генерации (цифры, регистр букв, спецсимволы).

Проект демонстрирует навыки работы со стандартными библиотеками Python, манипуляции со строками и реализацию комбинаторной логики.

---

## ✨ Основной функционал / Features

* **🎛️ Гибкая настройка пула символов:** Пользователь сам решает, из чего будет состоять пароль (цифры, строчные буквы, заглавные буквы, знаки пунктуации).
* **🔢 Массовая генерация:** Возможность создать как один, так и целую пачку уникальных паролей за один запуск.
* **📏 Кастомизация длины:** Полный контроль над количеством символов в генерируемых комбинациях.
* **🎲 Высокая случайность:** Использование встроенного модуля криптографического выбора случайных элементов гарантирует уникальность каждого пароля.

---

## 🛠️ Стек технологий / Tech Stack

* **Язык:** Python 3.x
* **Использованные модули (Стандартная библиотека):**
  * `random.choice` — для случайного выбора символов из сформированного пула.
  * `string` (`digits`, `ascii_lowercase`, `ascii_uppercase`, `punctuation`) — для быстрого доступа к готовым наборам безопасных символов.
* **Концепции:** Параллельная обработка списков (связка вопросов и типов данных через индексы), кастомные функции с передачей аргументов и возвратом значений (`return`).
* **Сборка:** Исполняемый бинарный файл (.exe) для операционной системы Windows.

## 🚀 Как запустить / How to Run

Вы можете использовать программу как готовое приложение или запустить её через исходный код Python.

### Вариант 1: Запуск готового `.exe` (Рекомендуется для пользователей)
Вам **не нужно** устанавливать Python.
1. Перейдите в раздел **[Releases](https://github.com/Mr-Sharkness/Password-Generator/releases)** справа.
2. Скачайте файл `password_generator.exe`.
3. Запустите его двойным кликом.

*Примечание: При первом запуске Windows Defender может выдать предупреждение SmartScreen. Нажмите "Подробнее" -> "Выполнить в любом случае".*

### Вариант 2: Запуск из исходного кода (Для разработчиков)
Для запуска и модификации кода вам понадобится **Python 3.x**:

```bash
# Клонировать репозиторий
git clone https://github.com/Mr-Sharkness/Password-Generator.git

# Перейти в папку проекта
cd Password-Generator

# Запустить приложение
py "password_generator.py"
